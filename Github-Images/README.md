# 🖼️ GitHub Images Generator

> Dynamic SVG tech stack badges, animated waves, and section dividers for GitHub Profile READMEs.

Part of the **[GitHub Trash](https://github.com/13507-IN/Github-Trash)** developer experience suite.

---

## ✨ Features

- **Tech Stack Badges Grid**: Clean, categorized glowing pills for TypeScript, React, Next.js, Docker, Python, Node.js, and 25+ technologies.
- **Animated Section Dividers**: Smooth CSS/SVG wave dividers and neon laser lines to split sections in your README.
- **Customizable**: Dark and light theme modes, custom colors, border radii, and category tags.

---

## 🚀 Quick Usage

### Generate Tech Stack Grid
\`\`\`bash
npx github-images --stack "typescript,react,nextjs,nodejs,tailwind,docker,postgres,python" --divider --output ./images
\`\`\`

### In Your GitHub README
\`\`\`markdown
<div align="center">
  <img src="./images/tech-stack.svg" alt="My Tech Stack" />
</div>

<img src="./images/wave-divider.svg" alt="Divider" width="100%" />
\`\`\`
